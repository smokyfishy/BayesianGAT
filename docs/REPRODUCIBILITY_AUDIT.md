# Original-code reproducibility and scientific integrity audit

The following observations are grounded in the supplied notebook source cells. Treat them as issues to **audit and document**, not reasons to erase the original experiment.

1. **DMD gene labels are curated, not comprehensive ground truth.** `DMD.ipynb` cells 59–61 list presumed DMD modifier genes and label every other graph node as class 0. Unknown/unlabeled genes are not independently verified negatives. Report as a weak-label / positive-unlabeled task unless true negatives are documented.
2. **Graph oversampling happens before splitting.** DMD cells 63–65 augment minority class nodes and then construct train/validation/test masks on the augmented graph. Synthetic relatives can cross splits, violating independence. For corrected benchmarks split ORIGINAL labeled entities before any augmentation; restrict augmentation and fitting of learned transformations to training. Provide an audit of graph transduction and any cross-split edges, and clearly distinguish transductive vs inductive evaluation.
3. **DMD kNN edges may use all-node features** (cell 62) and the graph contains potential transductive connections. A legitimate transductive evaluation is possible if clearly stated, but does not equal validation on unseen genes, populations, or independent patient cohorts. Never claim an inductive generalization result from it.
4. **GAT is variational-style only in name.** `EnhancedBayesianGAT` uses GATv2Conv, dropout/MC dropout, and a learnable temperature. It does not explicitly use a Bayesian weight posterior. Describe predictive uncertainty by MC dropout and check calibration with an independent calibration set; avoid claiming exact Bayesian inference.
5. **NFATC4 training target leaks into input.** `NFATC4.ipynb` cell 20 concatenates `mutation_flags` to its ESM feature vectors, then cell 25 sets `y=data.x[:, -1]`. The classifier sees its answer at train and evaluation time. A corrected model must remove the target flag from ALL inputs. Report old near-perfect metrics only as historical, methodologically invalid for new predictive claims.
6. **NFATC4 mutation labels are simulated, not observed per-residue pathogenicity.** Cell 4 populates residues in specified domains if an expression fold-change condition is met. These flags cannot establish pathogenic mutations or independent validation. Require observed, source-tracked residue-level labels to train scientifically meaningful supervised pathogenicity models; otherwise provide a clearly marked exploratory/simulation mode with no clinical conclusions.
7. **NFATC4 GVP is not a geometric vector perceptron as generally defined.** Cell 24's class named `GVP` applies scalar dense layers to feature vectors. Its `MultiHeadGVPConv` propagates scalar messages and does not explicitly incorporate vector channels, direction, or rotation-equivariance. Preserve and accurately name the *original scalar message-passing implementation*; optional true GVP architecture must be clearly presented as a new experiment, not an identical reproduction.
8. **NFATC4 sequence and coordinate indices** can differ: code uses Python zero-based offsets but domain/cluster tables sometimes use residue numbering. Validate PDB chain residues against UniProt Q14934, missing coordinates, sequence length (902 in original), insertion codes, and 0-based vs 1-based reporting. Never silently report zero-based index as a UniProt residue position.
9. **Preprocessing and scoring pitfalls.** Fit scalers and graph-derived learning only where evaluation protocol permits. Use stratified and repeated seeds where feasible, evaluate PR-AUC and ROC-AUC with observed labels, report class supports, confidence/calibration where valid. Do not report AUC when only one class is present. MC dropout alone is not proof of reliability.
10. **Protein clusters and annotations.** The original notebook hardcodes candidate ranges (36–44, 88–99, 104–115, 195–203, 278–283, 696–704, 747–753). Preserve these as historical/suggestive features, not validated DMD causal hotspots; reproduce cluster scoring from saved vectors separately and verify domains against a cited canonical source. Domain definitions vary in original cells.
11. **Saved Torch models are serialized and potentially unsafe from untrusted sources.** The supplied `.pt/.pth` came from the user's own Drive; load only when trusted. Default `torch.load(..., weights_only=True, map_location="cpu")` where possible. A PyG `Data` graph may require special handling; avoid arbitrary unpickling of untrusted artifacts.
12. **No PHI.** Do not add patient-identifiable records, credentials, authenticated Drive links or sensitive cohort data to the repository. Review all dataset licenses before GitHub publication.

Document these changes in `docs/LEGACY_VS_CORRECTED.md`; never overwrite the source notebooks or fabricate metrics to match prior reports.
